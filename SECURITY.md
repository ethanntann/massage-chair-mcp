# Security

This server controls a physical massage chair, so safety issues count as
security issues: anything that lets an agent start or keep the chair running
when it shouldn't, move the seat unexpectedly, or connect to the wrong device.

Please report problems privately through GitHub's
[security advisory form](https://github.com/ethanntann/massage-chair-mcp/security/advisories/new)
rather than a public issue.

Out of scope: the chair's own Bluetooth protocol has no pairing or
encryption. That's the product's design; this project can't change it.
